## Запуск

```sh
npm ci --prefix frontend
npm ci --prefix backend
npm run dev
```

Фронтенд откроется на http://localhost:3000. Для отдельного API: `npm run dev:backend` в другом терминале; укажите его URL в `frontend/.env.local` через `NEXT_PUBLIC_API_URL`. Без API работает актуальное общее ядро в браузере.

Локальные настройки `frontend/.env.local` перенесены из дизайн-версии и исключены из Git. Пустой шаблон доступен в `frontend/.env.example`. Для AI и голоса нужны действующие ключи OpenRouter/xAI и `NEXT_PUBLIC_VOICE_ENABLED=1`. Секретные ключи используются только серверными маршрутами Next.js.

## Интеграция

- Сохранены лендинг, анимации памяти и кампусов, визуальный стиль, голосовое интервью, ручной ввод и экраны основного пути.
- Сохранены свежий Express API, база 45 программ, движок, нормализация сохранённой памяти, сравнение полной стоимости и предупреждение о темпе маршрута.
- Микрофон включается явным нажатием; вход на страницу больше не начинает запись автоматически.
- Дизайн-интервью использует свежий адаптивный выбор вопросов и завершает диалог по состоянию ядра. Число реплик больше не означает полноту профиля.
- Обогащение моделью проверяется общим ядром; числа разбираются общими правилами. Асинхронное извлечение завершается до выбора следующего вопроса.
- Проверка демо читает реальную реплику новой анимированной сцены лендинга.
