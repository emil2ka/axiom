# AXIOM

AI-сервис персонального маршрута поступления: голосовое интервью → память о тебе → персональные университеты → сравнение → What If → маршрут и следующий шаг.

Проект для LOCUS Startup Hackathon 2026, кейс 02 «Персональный маршрут поступления».

## Статус

Ранняя стадия: репозиторий создан, разработка ведётся в 72-часовом окне хакатона (16–19 сентября 2026).

## Планируемый стек

- Frontend: Next.js (App Router), TypeScript, Tailwind CSS
- Backend: Node.js, TypeScript
- Деплой: Vercel (frontend), Railway (backend)

## Структура

- `frontend/` — клиентская часть
- `backend/` — серверная часть, данные университетов
- `shared/` — API-контракт
